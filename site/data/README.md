# site/data

Generated by `python3 scraper/scrape.py`. Not written by hand.

- `index.json` — every problem's statement, choices, answer, tags.
- `solutions/<contest_id>.json` — solutions, one file per contest.
- `report.json` — what the last scrape could not do (missing pages, unsplit
  choices, uncategorized problems, answer-key/boxed disagreements).
